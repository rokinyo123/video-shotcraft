# 1-ci bölüm: Adəm — Hazırlanacaqlar (kopyala-yapışdır)

Hər kod qutusunu olduğu kimi kopyalayın, üslub mətni artıq içinə əlavə olunub.

**Faylların adı:** şəkil → `K01.jpg`, video → `K01.mp4`. Green screen → `G01.mp4`.

**Negative prompt** (generatorda belə bir xana varsa, hamısı üçün eyni):
```
face, facial features, eyes, text, watermark, logo, cartoon, anime, bright saturated colors, modern objects
```

Cəmi: 19 şəkil+video, 22 yalnız şəkil, 6 fon şəkli, 4 green screen video.
