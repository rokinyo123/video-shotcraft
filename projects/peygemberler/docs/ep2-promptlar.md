# Həzrəti İdris — 1-ci dəqiqədən sonrakı hissə: klip promptları

**Səsləndirmə:** yekun ssenarinin 1-ci fəslindən sona qədər **bir faylda**. Hər abzasdan sonra təxminən 1 saniyə fasilə verin.

**Flow ayarı:** 16:9. Mümkünsə **8 saniyəlik** klip seçin, uzun səhnələr üçün lazımdır.
Hər promptun sonuna bunu əlavə edin:
```
cinematic, photorealistic, 16:9, slow camera movement, golden and dark color palette, volumetric light, film grain, no text, no watermark
```
**Qaydalar:**
- Peyğəmbərin üzü heç vaxt görünmür, yalnız arxadan və ya uzaqdan siluet.
- Mələklər bədənsiz, işıqdan qanadlar kimi göstərilir.

Cədvəldə **"KOD"** yazılan yerlərə klip lazım deyil. Onları mən animasiya ilə qururam: qlobus, sayğac, ayə kartı, soy ağacı və s.
**Təkrar istifadə:** Treylerdəki 7 klip (ZİQQURAT, OCAQ, İYNƏ, GİL, ÇUBUQ, BULUDLAR, İŞIQ SÜTUNU) yenidən işlədiləcək.
